🔄 Base Feature Architecture & Execution Journey
The primary end-to-end feature sequence driving ThreatLens — from live QR detection and threat report generation to cross-app redirection, background link guard, database sync, and user profile authentication.
BASE FEATURE 01INPUT
📷 Live Camera & Gallery Scanner
CameraX API streams live camera frames at 60fps to ML Kit Barcode Scanning. Users can also import gallery screenshots offline. QrDataParser.kt instantly decodes raw strings into URL, UPI, Wi-Fi, vCard, Credential, or Encrypted formats.
ScannerScreen.kt + QrDataParser.kt
BASE FEATURE 02VERDICT
📊 Threat Report Generation (URL, UPI, Wi-Fi)
Orchestrates 14 remote security APIs, zero-latency regex heuristics, and on-device AI to generate a unified 0–100 Safety Gauge. Displays an expandable per-engine report card, Gemini AI plain-English summary, and side-by-side metric comparison.
ThreatAnalyzer.kt + ResultBottomSheet.kt
BASE FEATURE 03ROUTING
🔗 Cross-App Redirection & Intent Router
When opening verified safe URLs or payloads, SmartRouter.kt queries Android package manager for installed native apps (wa.me ➔ WhatsApp, youtu.be ➔ YouTube, phonepe.com ➔ PhonePe) to route URLs directly while preventing browser loops.
SmartRouter.kt + DynamicLinkManager.kt
BASE FEATURE 04FINANCE
💰 UPI Payment Protection & Scam Alerts
Intercepts Indian UPI payment QR codes (upi://pay). Verifies VPA payee handles, flags ₹0 collect request scams, and computes a 60% heuristic + 40% ML statistical fraud risk score before opening payment apps.
UpiPaymentAnalyzer.kt + UpiTransactionMLEngine.kt
BASE FEATURE 05BACKGROUND
🛡️ Real-Time Link Guard (Background Service)
Android Accessibility Service monitoring link taps across third-party apps (WhatsApp, SMS, Gmail, Telegram). Intercepts suspicious URLs *before* browser launch, blocking phishing attempts system-wide automatically.
LinkGuardService.kt + LinkGuardPreferences.kt
BASE FEATURE 06CREATION
🎨 QR Code Studio & Design Generator
Professional QR code creation suite allowing custom gradient colors, eye module shapes, and logo compositing via Compose Canvas. Tracks campaign scan analytics and exports print-ready vector SVG/PDF files.
GenerateTab.kt + CustomQrGenerator.kt
BASE FEATURE 07PERSISTENCE
📜 Encrypted Scan History & Database Sync
Stores every scan record in Room database encrypted with SQLCipher AES-256 disk encryption (ScanDatabase.kt). Features reactive Kotlin Flow search, native PDF security audit export, and Firestore cloud synchronization.
ScanDatabase.kt + CloudSyncManager.kt
BASE FEATURE 08AUTH
🔑 Profile & Firebase Authentication System
User identity and profile management supporting Google One-Tap Sign-In and serverless SMS/Email OTP login dispatched via Vercel (send-otp.js). Syncs user settings, scan history, and threat reports across devices.
LoginScreen.kt + AuthViewModel.kt + send-otp.js
BASE FEATURE 09SECURITY
🔒 Encrypted Vault & Passphrase QR Codes
Encrypted QR generator transforming content into AES-256 GCM encrypted payloads readable only with a secret passphrase. Protected by Android Biometric face/fingerprint authentication and Hardware Keystore.
VaultScreen.kt + QrEncryptionEngine.kt
BASE FEATURE 10IDENTITY
🪪 W3C Digital Identity Credentials
Issues and cryptographically verifies W3C Verifiable Identity Credentials embedded in QR codes. Uses Ed25519 digital signatures to verify authenticity offline and detect single-character payload tampering.
VerifiableCredentialEngine.kt
BASE FEATURE 11EVENTS
🎟️ Event Ticket Management & Check-In
Complete event entry system for issuing encrypted guest tickets and performing offline gate check-in validation without internet connection, flagging duplicate scan attempts instantly.
EventManagerScreen.kt + EventDao.kt
BASE FEATURE 12AI ENGINE
🧠 Neural Core & Perceptron AI Dashboard
Native Kotlin Perceptron Neural Network computing zero-latency threat scores from 20+ feature signals (entropy, homographs, API verdicts). Updates weights via on-device Gradient Descent and merges global Hive Mind weights.
NeuralCoreScreen.kt + AILearningEngine.kt
